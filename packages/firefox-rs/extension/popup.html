Callisto tab bridge

Enter the pairing code from Callisto, then share the tab you want the agent to use. The agent can read and change that page.

Optional: allow access to all websites so a shared tab stays connected as it navigates. This grants the extension access to data on every website.

Browser access lets the agent inspect and manage tabs, cookies, history, bookmarks and downloads. Grant only to an agent you trust.

Optional agent containers separate cookies and logins for new agent tabs or windows. Existing tabs keep their current sessions.
