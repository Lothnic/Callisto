## 1. Serialization pipeline in `sidecar.ts`

The `eval` handler runs:

```ts
async function safeEval(code: string, mini: Mini): Promise<{ value: unknown; truncated: boolean }> {
  // 1. Build and run the async function
  const fn = new Function('mini', `return (async () => { ${code} })()`)
  const raw = await fn(mini)

  // 2. Special-case encode non-JSON-safe types before stringify
  const encoded = encodeValue(raw)

  // 3. Stringify with BigInt guard
  let json: string
  try {
    json = JSON.stringify(encoded, bigintReplacer)
  } catch (e) {
    if (String(e).includes('circular')) throw new Error('SerializeError: circular reference')
    throw e
  }

  // 4. Cap at 100 KB
  const cap = 100 * 1024
  if (json.length > cap) {
    return { value: json.slice(0, cap), truncated: true }
  }
  return { value: JSON.parse(json), truncated: false }
}

function encodeValue(v: unknown): unknown {
  if (Buffer.isBuffer(v) || v instanceof Uint8Array) {
    return { type: 'base64', data: Buffer.from(v).toString('base64') }
  }
  if (v === undefined) return null
  if (Array.isArray(v)) return v.map(encodeValue)
  if (v && typeof v === 'object') {
    return Object.fromEntries(Object.entries(v).map(([k, val]) => [k, encodeValue(val)]))
  }
  return v
}

function bigintReplacer(_key: string, val: unknown) {
  return typeof val === 'bigint' ? val.toString() : val
}
```

**`mini.close()` guard:** Before calling `fn(mini)`, wrap `mini.close` with a
stub that throws `"EvalError: mini.close() is not callable from eval"`. Restore
it after `fn` resolves. The wrapper is three lines.

**Timeout:** wrap `fn(mini)` in `Promise.race([fn(mini), timeout(60_000)])`.

## 2. Sidecar stdin/stdout framing

One JSON object per line on both stdin and stdout. The sidecar:

1. Reads stdin line by line (`readline.createInterface`).
2. Parses each line as JSON. If parse fails, writes
   `{ id: null, ok: false, error: "ParseError: invalid JSON" }`.
3. Dispatches to `launch | eval | close`.
4. Writes the response JSON + `\n` to stdout.
5. Flushes immediately (Node's `process.stdout` is not line-buffered by
   default; `process.stdout.write()` flushes synchronously on every call).

The sidecar exits cleanly when stdin closes (EOF) — no explicit shutdown signal
needed, though `close` is still the polite way.

## 3. `sidecar_client.py` — subprocess lifecycle

```python
class SidecarClient:
    def __init__(self, restart_budget: int = 1): ...

    async def start(self) -> None:
        # Spawns: callisto-sidecar (from $PATH)
        # Captures stdout for JSON-RPC, lets stderr flow to the terminal
        ...

    async def call(self, method: str, params: dict, *, timeout: float = 65.0) -> dict:
        # Raises SidecarDead if process has exited
        # Raises SidecarTimeout if no response within `timeout` seconds
        # Returns result dict on success
        # Raises SidecarError(message) on { ok: false }
        ...

    async def _watchdog(self) -> None:
        # asyncio.create_task; awaits process exit
        # On exit: sets self._dead = True
        # Does NOT auto-restart here — the restart logic is in call()
        ...

    async def _maybe_restart_chrome(self) -> None:
        # Called by call() when SidecarDead is raised for the first time
        # Kills old process, starts new one, issues launch()
        # Decrements restart_budget; raises SidecarDead if budget exhausted
        ...
```

**Request/response matching:** each call assigns a UUID as the `id`. The
response reader task correlates responses by `id` into a per-call `Future`.
This allows concurrent `call()` invocations in theory, but the loop serialises
them in practice.

**stderr passthrough:** the sidecar writes diagnostic lines to stderr (Node
startup noise, CDP errors). These flow directly to the terminal — don't capture
stderr in the client.

## 4. `package.json` additions to `@callisto/mini`

```json
{
  "bin": {
    "callisto-sidecar": "./src/sidecar.ts"
  },
  "scripts": {
    "sidecar": "tsx src/sidecar.ts"
  }
}
```

After `npm link` (dev) or `npm i -g @callisto/mini` (install), `callisto-sidecar`
is on `$PATH`. `tsx` is already a dev dependency — it's the shebang runner. The
shebang line at the top of `sidecar.ts`:

```ts
#!/usr/bin/env -S npx tsx
```

This works on macOS and Linux. On Windows, `npx tsx` would need a wrapper —
defer to a later issue.

`prompt.py` resolves the path relative to its own `__file__`:

```python
PROMPT_PATH = Path(__file__).parent / "prompts" / "system.md"

def load_system_prompt() -> str:
    return PROMPT_PATH.read_text(encoding="utf-8")
```

Token count test in `test_prompt.py`:

```python
def test_prompt_token_budget():
    text = load_system_prompt()
    # Rough: 1 token ≈ 4 chars. 12K tokens = 48K chars.
    assert len(text) < 48_000, f"System prompt too long: {len(text)} chars"
```

test interface.

## 6. `@requires_approval` — wiring

```python
SENSITIVE_TOOLS = {"bash"}  # extend as needed: "submit_form", "send_message"

def requires_approval(fn):
    fn._requires_approval = True
    return fn
```

In `loop.py`, before dispatching:

```python
tool_fn = tool_registry[call.name]
if getattr(tool_fn, "_requires_approval", False) or call.name in SENSITIVE_TOOLS:
    confirmed = await ask(f"Approve: {call.name}({call.arguments})?")
    if not confirmed:
        history.append(tool_result(call.id, "User denied this action."))
        continue
```

`SENSITIVE_TOOLS` starts as `{"bash"}` since bash is the highest-privilege
tool in the loop. `repl` is lower privilege (sandboxed to the browser session).

## 7. `compaction.py` — day-one stub

```python
def compact(messages: list[dict], token_budget: int = 80_000) -> list[dict]:
    """
    Naive compaction: keep the system prompt + last N turns that fit.
    Phase 4 will replace this with semantic summarisation.
    """
    system = [m for m in messages if m["role"] == "system"]
    turns  = [m for m in messages if m["role"] != "system"]

    # 1 token ≈ 4 chars; rough but good enough for a stub
    budget_chars = token_budget * 4
    kept = []
    chars = sum(len(json.dumps(m)) for m in system)
    for m in reversed(turns):
        mc = len(json.dumps(m))
        if chars + mc > budget_chars:
            break
        kept.append(m)
        chars += mc
    return system + list(reversed(kept))
```

Called at the top of each loop iteration before `model.chat(history, tools)`.

## 8. Audit log format

File: `~/.callisto/sessions/<session-id>/audit.jsonl`

Each record:
```json
{
  "ts": "2026-07-07T02:47:33Z",
  "step": 3,
  "type": "tool_call",
  "call": { "name": "repl", "arguments": { "code": "..." } },
  "result": { "value": "...", "truncated": false },
  "duration_ms": 412
}
```

Final record type `"task_end"` carries `{ "status": "success|failure|error", "summary": "..." }`.

## 9. Mini methods safe/unsafe from `eval`

| Method | Callable from `eval`? | Notes |
|--------|----------------------|-------|
| `goto`, `back`, `forward`, `reload` | ✅ | Normal navigation |
| `click`, `fill`, `type`, `press`, `scroll` | ✅ | Normal interaction |
| `screenshot` | ✅ | Returns `{ type: "base64", data: "..." }` |
| `snapshot` | ✅ | Returns `{ url, title, text }` |
| `evaluate` | ✅ | Nested JS eval |
| `waitFor` | ✅ | Async wait, subject to 60s eval timeout |
| `tabs.new`, `tabs.switch`, `tabs.close` | ✅ | Fine |
| `cookies.get/set/clear` | ✅ | Fine |
| `localStorage`, `sessionStorage` | ✅ | Fine |
| `pages()` | ✅ | Fine |
| `close()` | ❌ | **Blocked** — sidecar owns lifecycle |
| `Mini.launch()` | ❌ | **Blocked** — static method, not in scope anyway |
