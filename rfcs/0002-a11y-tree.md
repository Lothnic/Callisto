# RFC 0002 — Custom accessibility tree

- **Status:** Accepted
- **Phase:** 2
- **Author:** Lothnic

## Summary

Replace the stub `snapshot()` with a real perception layer: a pruned,
ref-annotated, iframe-aware accessibility tree serialized to compact indented
text. This is what the LLM sees. Denser tree → fewer tokens; stable refs →
fewer re-snapshots; state annotations → fewer hallucinations.

## Pipeline

```
CDP Accessibility.getFullAXTree (per frame)
  → normalize        (AXNode → RawNode; frame-qualified ids; extract state)
  → stitch iframes   (graft child frame root under its owner <iframe> node)
  → prune            (drop noise, hoist wrappers, collapse)
  → allocate refs    (stable by backendDOMNodeId)
  → format           (indented text)
```

Modules: `ax-prune.ts`, `ax-refs.ts`, `ax-format.ts` (all pure), orchestrated
by `snapshot.ts`.

## Node model

```ts
interface RawNode {
  id: string          // `${frameId}:${nodeId}` — nodeIds collide across frames
  role: string        // CDP role token, verbatim (mixed case: 'button', 'StaticText')
  name: string
  description?: string
  value?: string
  state: string[]     // ['focused','checked',...] from AXProperties
  backendDOMNodeId?: number
  frameId: string
  childIds: string[]
}
```

`PrunedNode` is the same minus `id`/`childIds`, plus `children: PrunedNode[]`
and an optional `ref` filled after allocation.

## Pruning heuristics

Role tables key off the **verbatim CDP role token**. Three buckets:

- **Transparent** (`RootWebArea`, `WebArea`, `none`, `presentation`, `generic`,
  `InlineTextBox`, `LineBreak`, and any `ignored` node): never kept; children
  hoisted to the parent. This is the main "collapse wrappers" mechanism.
- **Interactive** (`button`, `link`, `textbox`, `checkbox`, `radio`,
  `combobox`, `menuitem`, `tab`, `switch`, `slider`, …): always kept, always
  reffed.
- **Structural / landmark** (`main`, `navigation`, `banner`, `contentinfo`,
  `region`, `form`, `search`, `heading`, `list`, `listitem`, `table`, `dialog`,
  `img`, …): kept for context, not reffed.

Special cases:
- `StaticText` — kept only if it has a name **not equal to the nearest kept
  ancestor's name** (kills the "button 'Search' contains text 'Search'"
  duplication). Empty text dropped.
- `group` — kept only if named (named groups are semantic, e.g. radiogroups).
- Catch-all: an unrecognized role with a non-empty name is kept; nameless is
  hoisted.

Landmarks are **not** dropped naively (roadmap pitfall) — `main`/`nav` live in
the structural set.

## Ref allocation & stability

`RefRegistry` maps `backendDOMNodeId → ax-N`, allocated once and reused forever.
Re-snapshotting the same page yields identical refs for surviving nodes. A
toggled checkbox keeps its backend node, so its ref is stable across the state
change — that's the 80%-survival criterion, met structurally rather than by
fuzzy diffing.

`RefRegistry` also stores `{role, name, frameId}` per ref so a stale ref can be
remapped heuristically (same role+name) — used by re-resolution.

## Resolution (ref → coordinates)

Lazy, at action time: `DOM.getBoxModel({ backendNodeId })` → center of the
content quad. No box-model calls during snapshot. A detached node throws a
clear "ref stale — re-snapshot" error rather than clicking the wrong spot.

## Iframe stitching

`getFullAXTree` is scoped per frame, so subframe content must be grafted in:

1. `Page.getFrameTree` → flatten to frame ids.
2. Per frame: `getFullAXTree({ frameId })`, normalize with frame-qualified ids.
3. Per non-main frame: `DOM.getFrameOwner({ frameId })` → owner `<iframe>`
   backendId → find that node in the assembled map → append the child frame's
   root id to its `childIds`.

Cross-origin OOPIFs: if `getFrameOwner` fails, the frame's tree degrades to a
top-level root instead of vanishing (logged, not silent).

## Output format

```
[ax-3] button "Add to Cart" {focused}
navigation "Main"
  [ax-7] link "Sign in"
[ax-12] textbox "Search" =laptop
```

`[ref] role "name" {state} =value`. Refs only on interactive nodes. Two-space
indent per depth.

## Non-goals

No visual/vision fallback yet (bounding-box hint deferred). No tree-diff remap
beyond role+name (backendDOMNodeId hashing makes it unnecessary for the common
case). No shadow-DOM-specific walking — the AX tree already flattens open
shadow roots.
