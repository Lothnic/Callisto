# Changes supported by this screening

Keep product changes separate from the saved screening cohort. Reusing these tasks for tuning makes them development tasks; a later claim needs a fresh held-out cohort and matched dependency versions.

1. **Stop unnecessary connection discovery.** Four of six account trials requested `pair` while already connected. The compact description says “Start with status or pair,” despite the task being provisioned and authenticated. Prefer status only when runtime state is unknown, and pair only when disconnected/unpaired. Do not remove manual pairing or browser consent. Verify in fresh conversations that ready sessions begin useful page work without pairing-code requests.
2. **Make ordinary argument repair self-contained.** Public `press` supplied a ref even though only key is accepted; account `check` omitted `checked`; two account `browser` calls omitted action. Whole-plan prevalidation prevented partial dispatch, which is correct. Improve operation examples and structured repair hints, then measure discovery/repair calls on new tasks. The previously measured fill/text/select-label patterns did not recur, but this is not a causal ablation.
3. **Provide bounded verbatim evidence.** Callisto returned all requested public facts, but two answers stitched snapshot fragments into purported exact quotes. Browse passed both. Add or document a concise way to obtain contiguous source text with URL/context, and teach the host to copy that evidence exactly. Retain the strict quote rule. Verify both factual correctness and quotation provenance on unfamiliar pages.
4. **Reduce repeated observations after input.** Account Callisto used 24 snapshots, 11 help calls, five status calls and four pair calls, versus Browse's 36 execute calls and one tabs call. Callisto returned 76,443 original UTF-8 bytes versus 17,695. Prefer focused reads, typed projections, composed operations and one meaningful state verification. MCP calls differ from model requests and underlying browser commands; lower counts alone do not establish lower cost.
5. **Measure native OpenCode composition when available.** The free-model preflight was quota-blocked. The successful Codex default-host suites do not exercise OpenCode's named tools or Code Mode. Retain native initialization and actual client identity, compare compact/native with one model and pinned versions, audit direct API access equally, and retain failures. Do not credit an unrun facade with token savings.

The public all-attempt uncached input gap is +5.3%, while the account gap is +24.7%. Public success is lower for Callisto under the strict rule. Improvements should target completion plus total task usage, rather than catalog bytes or one favorable latency example. The official retrieval subset is useful external evidence but has only one attempt per engine/task and does not establish a full-suite result.
